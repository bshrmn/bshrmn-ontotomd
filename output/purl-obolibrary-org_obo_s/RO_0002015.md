# Description Properties
- propertyKey: [definition](c:\Users\bsher\Documents\bshrmn-ontotomd\output\purl-obolibrary-org_obo_s\IAO_0000115.md)
  - propertyValue: A relationship that holds between a GO molecular function and a component of that molecular function that positively regulates the activity of the whole.  More formally, A 'has regulatory component activity' B iff :A and B are GO molecular functions (GO_0003674), A has_component B and A is positively regulated by B.
- propertyKey: [comment](c:\Users\bsher\Documents\bshrmn-ontotomd\output\www-w3-org_2000_01_rdf-schema_h\comment.md)
  - propertyValue: By convention GO molecular functions are classified by their effector function and internal regulatory functions are treated as components.  So, for example calmodulin has a protein binding activity that has positive regulatory component activity calcium binding activity. Receptor tyrosine kinase activity is a tyrosine kinase activity that has positive regulatory component 'ligand binding'.
