Function in this sense denotes an action, or activity, that a gene product (or a complex) performs. - propertyKey: [comment](c:\Users\bsher\Documents\bshrmn-ontotomd\output\www-w3-org_2000_01_rdf-schema_h\comment.md)
  - propertyValue: Note that, in addition to forming the root of the molecular function ontology, this term is recommended for use for the annotation of gene products whose molecular function is unknown. When this term is used for annotation, it indicates that no information was available about the molecular function of the gene product annotated as of the date the annotation was made; the evidence code 'no data' (ND), is used to indicate this. Despite its name, this is not a type of 'function' in the sense typically defined by upper ontologies such as Basic Formal Ontology (BFO). It is instead a BFO:process carried out by a single gene product or complex.
